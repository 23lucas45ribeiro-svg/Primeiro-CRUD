# Primeiro-CRUD
Meu primeiro Crud, para eu ir desenvolvendo mais minha habilidades com JavaScript e aplicações resposivas.

Este projeto é uma espécie de aprendizagem constante, por que pretendo usar todas as minhas tecnologias neste sistema, partindo da criação do próprio CRUD até colocá-lo em container utilizando o Docker.

Neste momento estou estilizado o projeto, organizando o arquivo style.css para deixar um design mais agradável, porém no momento está tudo meio que um teste pra justamente ir aprendendo como fazer um mine-projeto, mas bem completo, para que eu possa aplicar isso em sistemas mais complexos no futuro.
